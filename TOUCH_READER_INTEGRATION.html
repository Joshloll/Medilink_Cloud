🔧 Touch Reader Integration Template

Guide for integrating the Touch Reader debugging tool into your Medilink pages.

📦 Overview

The Touch Reader is already integrated into all main Medilink pages. Use this guide if you're:

  • Creating new HTML pages for the system
  • Understanding the integration method
  • Troubleshooting integration issues

✅ Quick Integration Checklist

For pages in the same folder as debug.js (Admin folder):

<script src="debug.js"></script>

For pages in subfolders (Doctor, Patient folders):

<script src="../debug.js"></script>

📍 Proper Placement in HTML

Add the script tag at the end of your HTML file, just before the closing </body> tag:

</main> <!-- Other scripts --> <script src="app.js"></script> <script src="components/navigation.js"></script> <!-- Touch Reader Debug Tool (MUST BE LAST) --> <script src="../debug.js"></script> </body> </html>

🆕 Adding to New Pages

Step 1: Determine Location

If your new page is in the Admin folder:

<script src="debug.js"></script>

If your new page is in the Doctor or Patient folder:

<script src="../debug.js"></script>
Step 2: Add to HTML Template

Include the script in your HTML file structure:

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>My New Page</title> <!-- Your head content --> </head> <body> <!-- Your page content --> <!-- Application Scripts --> <script src="app.js"></script> <!-- Touch Reader Debug Tool (MUST BE LAST) --> <script src="debug.js"></script> </body> </html>
Step 3: Verify Integration

After adding the script, check:

  • Refresh the page
  • Look for blue "Touch Reader" button in top-right corner
  • Click the button - it should turn green
  • Bottom-right panel should appear and say "Click an element to see its details"
  • Click any element on the page - info should appear in the panel

// After debug.js loads, access globally: window.touchReader // TouchReader instance window.TouchReader // TouchReader class // Example: Check if enabled if (window.touchReader.isEnabled) { console.log('Touch Reader is active'); } // Example: Toggle programmatically window.touchReader.toggle(); // Example: Access click history console.log(window.touchReader.lastClickedElements);

Common Integration Patterns

Pattern 1: Admin Pages (Same Folder)

Repository structure: /Admin/ Admin_Dashboard.html Admin_Patients.html debug.js ← in Admin folder Integration: <script src="debug.js"></script>

Pattern 2: Subfolder Pages

Repository structure: /debug.js ← root level /Doctor/ Dashboard.html /components/ dashboard.js Integration: <script src="../debug.js"></script>

Pattern 3: Deep Nested Pages

If nested deeper, adjust path: /debug.js /Project/ /SubFolder/ Page.html Integration: <script src="../../debug.js"></script>

🐛 Troubleshooting

❌ Button Not Appearing?

Issue: No "Touch Reader" button visible

Solutions:

  • Check the script path is correct (use ../debug.js for subfolders)
  • Open DevTools (F12) and check for console errors
  • Verify script is loading (Network tab)
  • Wait for page to fully load before testing
  • Try adding defer to script tag: <script src="debug.js" defer></script>

❌ Button Appears But Won't Toggle?

Issue: Button exists but clicking doesn't work

Solutions:

  • Check for JavaScript errors in DevTools Console
  • Ensure DOM is fully loaded before script runs
  • Check if another script is overriding event listeners
  • Try keyboard shortcut: Ctrl+Shift+R

❌ Panel Not Showing After Toggle?

Issue: Button turns green but no panel appears

Solutions:

  • Check if z-index is being overridden by other elements
  • Verify body element is not hidden
  • Check for CSS conflicts in your styles
  • Clear browser cache and refresh

❌ Click Detection Not Working?

Issue: Tool is on but clicks aren't detected

Solutions:

  • Try clicking different elements
  • Check if event propagation is stopped elsewhere
  • Open DevTools Console to see if logs appear
  • Try keyboard shortcut Ctrl+Shift+R to reset
